# 多目标 RL 与交通信号控制

[多目标](../index.md#pareto) · [约束优化](../index.md#constraints) · [交通系统](../index.md#traffic)

目标是为同一路口选择兼顾通行效率与排放的信号策略。这个例子采用仿真设定，可先用少量固定配时策略建立对照，再引入 RL。

## 从路口到 RL 模型

| RL 对象 | 本例中的定义 |
| --- | --- |
| 状态 | 各车道的队列长度、当前相位、相位持续时间，以及可获得的近期到达统计。 |
| 动作 | 保持当前相位，或在满足最短绿灯与清空时段后切换相位。 |
| 奖励向量 | 每个时间步记录负延误与负排放，按共同的评估时段汇总两个指标。 |
| 预算 | 若有排放预算，可限制评估时段内的期望累计排放。若要求超限概率低于阈值，则使用机会约束。 |
| 评估 | 在同一组需求场景下报告平均延误与排放，分开记录高峰和非高峰情况。 |

## 用四个候选策略说明选择过程

下表为示意数据，两个成本已使用固定尺度归一化，数值越低越好。候选集合限定为 A、B、C、D 四个独立部署的策略。

| 策略 | 延误成本 | 排放成本 |
| --- | ---: | ---: |
| A | 10 | 8 |
| B | 12 | 6 |
| C | 16 | 1 |
| D | 15 | 9 |

1. **筛选前沿。** A 的两个成本都优于 D。A、B、C 在候选集合中互不支配。
2. **用预算选策略。** 若排放成本上限为 6，B 和 C 可行，B 的延误更低，因此选择 B。
3. **比较加权法。** 对目标 `w × 延误 + (1 − w) × 排放`，B 优于或等于 A 需要 `w ≤ 1/2`，优于或等于 C 需要 `w ≥ 5/9`。没有一个权重同时满足两者，所以 B 可以由预算法选出，线性加权却会遗漏它。
4. **明确是否允许混合。** 若可在每次运行前以 2/3、1/3 的概率分别选择 A、C，长期平均成本为 `(12, 17/3)`，在期望指标下支配 B。若排放上限作用于每次运行，混合策略仍可能超限。

## 如何转化为实验

用固定配时策略作基线，分别训练加权奖励策略和带期望排放预算的策略。扫过多组权重和预算，画出全部策略的延误—排放散点并标出非支配点。比较时使用相同的场景、训练预算与评估方式。对带预算的策略同时报告预算满足程度和超限频率，以区分期望约束与逐次运行的表现。
