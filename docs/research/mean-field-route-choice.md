# 平均场 RL 与出行路线选择

[平均场](../index.md#mean-field) · [多智能体](../index.md#multi-agent) · [交通系统](../index.md#traffic)

大量车辆在两条连接同一起讫点的道路上出行。路线成本随流量变化，单车动作对宏观流量的影响在大群体中较小，适合用群体分布表达拥堵。

## 从交通分配到学习问题

| 对象 | 本例中的定义 |
| --- | --- |
| 个体状态 | 当前路段、目的地、车辆类型和可观测出行时段。 |
| 个体动作 | 在分流点选择路线，或在后续可改道节点选择下一路段。 |
| 群体量 | 按时段估计各路段占有量或流量，可进一步按车辆类型统计。 |
| 个体奖励 | 负行程时间，可加入收费成本以研究拥堵定价。 |
| 群体目标 | 全网总出行时间或人均出行时间，可同时报告不同类型的成本分布。 |

若仅在起点选一次路线，给定流量时可将问题视为一次性选择。加入多路段决策与随时间变化的拥堵后，才需要用序贯模型描述当前动作对后续状态和回报的影响。

## 两条 RL 路线

- **学习个体均衡。** 先固定一份群体流量估计，在给定流量的仿真数据上学习代表性驾驶者的策略。再让群体采用该策略，更新群体流量。检查更新后的流量和原假设是否一致，以及车辆单方面改变策略还能降低多少出行成本。
- **学习群体控制。** 将群体分布作为状态，用分流比例或引导策略作为控制量，学习以全网成本为目标的策略。数字仿真中还应记录引导遵从率，并检查分流方案对真实行为假设的敏感性。

## 一个可手算的对照

把总需求归一化为 1，令选择 A 路的比例为 `x`。A 路成本为 `x`，B 路成本恒为 `1`。

- **个体均衡。** 当 `x < 1` 时 A 更便宜，B 路车辆有改走 A 的动机。均衡为 `x = 1`，平均成本为 1。
- **群体最优。** 平均成本为 `x² + 1 − x`，在 `x = 1/2` 时达到最小值 `3/4`。一半流量走 B 可以降低全体车辆的平均成本。

这是用于验证实现的静态基准。扩展为多时段仿真后，可比较均衡间隙、全网成本和群体预测误差，并在不同车辆规模下重复评估。
