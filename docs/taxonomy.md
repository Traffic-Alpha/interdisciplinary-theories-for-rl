# 分类与扩展指南

首页的 11 个板块兼顾理论领域和 RL 研究问题，便于浏览。新增独立笔记时，按笔记所解释的数学对象确定主归属，再用研究路线和交叉链接连接相关条目。同一概念可以从多个板块进入，其完整定义与推导集中写在一篇笔记中。

[专题与标签索引](index.md)提供已展开笔记的入口。正文末尾的交叉引用负责说明值得一起阅读的概念，例如平均场博弈与均衡计算。标签负责把不同章节中的笔记按主题或应用聚在一起，例如「约束优化」可以同时找到最优性理论和交通信号案例。

## 条目归档

| 条目类型 | 回答的问题 | 归档示例 |
| --- | --- | --- |
| 模型 | 系统、信息和交互如何表示？ | 马尔可夫博弈归入博弈论，CMDP 归入序贯决策。 |
| 解概念 | 哪些决策或策略可以视为解？ | 纳什均衡、相关均衡和粗相关均衡归入博弈论。 |
| 分析工具 | 用什么结构或条件刻画性质？ | KKT 条件归入数学优化，Fisher 信息矩阵归入信息几何。 |
| 通用算法 | 用什么更新规则求解一类问题？ | 外梯度和 Mirror-Prox 归入数学优化，Sinkhorn 算法归入最优传输。 |
| RL 方法 | 理论如何变成具体的策略学习过程？ | 策略梯度归入策略学习，平均场 RL 归入大规模多智能体学习。 |

归档根据笔记的内容确定。以自然梯度为例，几何定义和推导归入信息几何，比较自然梯度与信赖域更新的笔记则归入策略优化路线。首页可以分别用一句话呈现几何和应用两种视角。

### 容易混淆的边界

- **平均场**要注明近似对象。平均场博弈关注代表性个体的最优响应与群体分布的一致性，平均场控制关注群体目标下的联合最优控制。均值场变分推断使用因子化近似，统计物理的平均场近似则用有效场描述相互作用。各条目通过术语与推导关联。
- **均衡与计算**使用不同条目类型。纳什、相关与粗相关均衡是解概念。虚拟博弈和遗憾匹配是学习动态或算法。外梯度与 Mirror-Prox 的适用条件在优化笔记中说明，博弈笔记再明确所求均衡及对应的算子假设。经典遗憾匹配的结论针对经验联合分布。 [Hart 与 Mas-Colell 的遗憾匹配论文](https://math.huji.ac.il/~hart/papers/adapt.pdf)
- **约束与风险**按数学语义查找。CMDP 是序贯决策模型，成本上界可通过拉格朗日方法处理。机会约束限制违约概率，CVaR 描述尾部风险，DRO 在候选分布集合上考察最坏情形。安全研究笔记比较这些形式对应的保证。 [Rockafellar 与 Uryasev 的 CVaR 论文](https://sites.math.washington.edu/~rtr/papers/rtr187-CVaR2.pdf)
- **分布强化学习**（distributional RL）学习回报分布，可与风险目标结合。用“分布式强化学习”（distributed RL）指分布式计算或学习，两个术语分别建索引。 [Bellemare、Dabney 与 Munos 的分布强化学习论文](https://proceedings.mlr.press/v70/bellemare17a.html)

## 研究问题索引

每一行是一条笔记路线。新增路线时写清决策问题、所用理论以及能比较的结果。

| 研究问题 | 理论如何进入 RL | 可比较的结果 |
| --- | --- | --- |
| 如何稳定地更新策略？ | 从策略梯度出发，用 Fisher 度量、镜像下降、近端或信赖域方法解释更新约束，比较 TRPO、PPO 与镜像策略优化。可另设熵正则与复制者动力学路线。 | 回报、策略散度、样本效率、更新稳定性 |
| 如何学习多主体均衡？ | 先选马尔可夫博弈与均衡概念，再比较最佳响应、无悔学习和适用的变分不等式求解方法。 | 均衡间隙、遗憾、对训练对手变化的表现 |
| 如何扩展到大规模群体？ | 用平均场博弈或控制建模，再比较平均场 RL 与有限主体基线，报告异质性建模与有限规模误差。 | 规模、通信量、群体成本、近似误差 |
| 如何处理安全、风险与资源？ | 区分期望成本、违约概率与尾部风险，分别讨论 CMDP、机会约束及 CVaR。通过鲁棒控制、DRO、控制障碍函数或可达性分析补充不同层次的保证。 | 违反率、尾部损失、收益、测试分布外表现 |
| 如何在模型或部分观测下规划？ | 用滤波或近似推断维护信念状态，对接动态规划、MPC 或模型式 RL。 | 规划耗时、模型误差、闭环性能 |
| 如何表示或迁移策略与分布？ | 比较能量策略、熵正则、最优传输与流形表示，说明比较的是策略分布、占用测度还是回报分布。 | 对齐误差、目标环境性能、采样成本 |
| 如何分解复杂决策任务？ | 根据耦合约束与上下层依赖选择 ADMM、对偶分解或双层优化，对接交通控制、资源分配或分布式学习。 | 全局目标、约束残差、通信量、规模增长时的成本 |

## 扩展规则

1. **先更新入口。** 在 [README 主题目录](../README.md#主题目录)下给新条目补充中英文名称及一句核心思想。定义、模型、通用算法或定理按数学对象归档。应用、算法比较或跨理论推导按研究问题归档。交通、机器人等场景可作为研究笔记的标签。
2. **选择一个主归属。** 按条目的核心对象选最贴近的分支。若两个笔记有不同的假设和结论，可以分别建条目，例如平均场博弈与平均场控制。若两处共享同一套定义与推导，保留一个条目并链接过去。
3. **用少量标签表达交叉维度。** 可记录主体结构（单主体、多主体、群体）、观测（完全、部分）、时间（离散、连续）和目标（期望、风险、鲁棒、约束）。优先复用[专题索引](index.md#按标签查找)中已有的标签。新增标签时在索引注册一个稳定锚点，并从专题笔记链接回该锚点。
4. **写成独立笔记时再建立文件。** 理论笔记可放在 `docs/theory/<topic>.md`，研究笔记可放在 `docs/research/<question>.md`。文件名使用稳定的英文短名，标题保留中英文，完成初稿后从首页或研究问题索引添加相对链接。
5. **按检索需要调整层级。** 先扩充分支，累积足够相关主题后再拆章。新增一级学科时写出它的研究对象、与现有学科的边界，以及代表分支。因果推断、统计学习等后续主题可按这套规则纳入。

### 扩展示例

以交通信号控制为例，可从首页的 [CMDP 与机会约束](../README.md#6-约束层次与多目标优化)出发，写一篇研究笔记比较两种排队约束。CMDP 可以限制一段时间内的期望累计排队成本，机会约束可以限制在同一时间范围内排队长度超过阈值的概率。实验可固定路网与需求设定，分别报告延误、累计排队成本和超限率，并明确超限事件是单时刻超限还是整段运行中至少一次超限。
