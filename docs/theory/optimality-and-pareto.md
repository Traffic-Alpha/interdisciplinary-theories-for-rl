# 最优性与帕累托权衡

**Optimality and Pareto Trade-offs**

[多目标](../index.md#pareto) · [约束优化](../index.md#constraints)

给定可行域和目标后，先判断一个解能否改进，再明确由谁、依据什么规则选择最终方案。以交通控制为例，延误、排放和安全可能有各自的最优值，单个信号策略未必能同时实现这些值。

## 单目标如何判定最优

| 概念 | 判定依据 |
| --- | --- |
| 全局最优 | 在整个可行域内比较，候选解的目标值至少和任何可行解一样好。 |
| 局部最优 | 在候选解附近比较，邻域内没有更优的可行解。 |
| 一阶驻点 | 对可微的无约束内点，梯度为零是局部最优的必要条件，最大值和鞍点也可能满足。 |
| 二阶条件 | 对无约束的二阶连续可微问题，局部极小点处 Hessian 必须半正定。在驻点处，Hessian 正定足以推出严格局部极小。 |
| KKT 条件 | 约束资格成立时，可微问题的局部最优解需满足驻点、原始可行性、对偶可行性与互补松弛条件。在凸问题中，满足 KKT 可证全局最优。 |

例如，最小化凸函数时，局部最优也是全局最优。策略神经网络的参数优化通常涉及非凸目标，训练曲线停止上升只能作为经验现象，需要另行判断最优性。[Boyd 与 Vandenberghe，第 4–5 章](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf)

## 多目标如何选解

以同时最小化延误和排放为例。如果策略 A 在两个指标上都不比 B 差，并且至少一个指标严格更好，则 A **支配** B。没有被任何可行策略支配的策略属于帕累托最优集合，其对应的指标向量组成**帕累托前沿**。前沿可能有很多点，选择哪一点取决于偏好、预算或优先级。

| 决策条件 | 做法 | 选择依据 |
| --- | --- | --- |
| 已知目标之间的交换比例 | 加权求和 | 先明确量纲和权重，再优化标量目标。非凸可达目标集合中，线性权重可能遗漏部分帕累托点。 |
| 某个指标有明确预算 | ε-约束 | 优化主目标，把另一目标写为上界或下界，然后改变门槛探索可行解。遇到主目标并列时可用次目标打破平局。 |
| 目标有严格优先级 | 字典序优化 | 先优化最高优先级目标，再在保持上一级最优值的解中优化下一目标。 |
| 偏好将在部署时给定 | 学习并保留候选策略集合 | 比较各策略的向量回报、前沿覆盖和部署时的可选范围。 |

对于序贯决策，目标可以是各指标的期望累计回报。若用户的效用对回报向量是非线性的，还要区分“对期望回报计算效用”和“对每条轨迹的效用取期望”，两者通常产生不同的策略排序。[Roijers 等，多目标序贯决策综述](https://arxiv.org/abs/1402.0590)
