# 平均场方法

**Mean-field Methods**

[平均场](../index.md#mean-field) · [多智能体](../index.md#multi-agent)

平均场方法通过宏观量降低大量交互带来的建模或计算复杂度。不同领域使用“平均场”时，所近似的对象和求解条件各有含义。

| 方法 | 宏观量或近似对象 | 主要问题 |
| --- | --- | --- |
| 群体交互的平均场近似 | 状态、行动或类型的群体分布及其统计量 | 如何用汇总量近似众多个体对单个主体的影响？ |
| 平均场博弈（MFG） | 代表性主体面对的群体分布 | 给定分布求个体最优响应，个体采用该响应后的分布能否与给定分布一致？ |
| 平均场控制（MFC） | 受控制策略影响的群体分布 | 选择策略时考虑分布如何变化，怎样优化群体层面的目标？ |
| 平均场 RL | 从观测、模拟或经验估计的群体量 | 动力学或收益未知时，如何用群体量学习个体策略、均衡或群体控制策略？ |
| 均值场变分推断 | 由若干独立因子相乘构成的近似后验 | 如何降低概率推断的计算成本？[README · 后验推断与计算](../../README.md#后验推断与计算) |
| 统计物理中的平均场近似 | 自旋等局部变量所受到的有效场 | 如何用自洽的平均作用研究宏观性质？[README · 宏观近似与计算](../../README.md#宏观近似与计算) |

## 如何判断群体近似是否合适

- **先找交互尺度。** 车辆可能主要受同一路段或邻近车流影响，考虑按路段统计，再与全网平均量作对照。
- **区分异质性来源。** 若通勤者与货运车辆的成本、可选路线或动力学不同，可以按类型分别建模。若影响主要来自网络邻接关系，还要保留局部交互结构。
- **检查有限规模误差。** 在不同车流规模下比较群体预测与逐主体仿真的拥堵、路线占比和成本，记录哪些条件下偏差较大。
- **区分求解对象与验证指标。** 均衡用偏离可获得的收益与分布一致性衡量，群体控制用总体成本衡量。平均场近似本身还可以用个体仿真与群体预测之间的偏差衡量。
